# alfimov.kz

SEO-сайт маркетингового агентства Alfimov. Статический, собирается скриптом на Python без зависимостей.

## Как устроено

| Что | Где |
|---|---|
| Тексты RU | `src/content_ru.py` |
| Тексты KZ | `src/content_kz.py` |
| Шаблоны, SEO-разметка, sitemap | `build.py` |
| Стили и скрипты | `static/assets/` |
| Обработчик формы → Telegram | `static/api/send.php` |
| Редиректы (https, www, alfimov.pro) | `static/.htaccess` |
| Блог и админка (PHP на хостинге) | `static/_blog/`, `static/admin/` — https://alfimov.kz/admin/ |
| Статьи блога | на хостинге в `alfimov-data/` (стартовый набор — `content/articles/`) |

Страницы: главная, 7 услуг, контакты — на русском (`/`) и казахском (`/kz/`), связаны через hreflang.

## Локально

```
python3 build.py --serve   # http://localhost:8000
```

## Блог и SEO-статьи

Блог и админка живут **на хостинге** (PHP), компьютер для них не нужен: https://alfimov.kz/admin/ —
логин и пароль, работает и с телефона. Основные страницы — статика из `build.py`.

- `static/_blog/lib.php` — статьи, расписание, markdown, страницы блога (оформление берётся из
  `_blog/parts.json`, его пишет `build.py` теми же функциями, что и весь сайт).
- `static/_blog/router.php` — `/`, `/blog/`, `/blog/<slug>/`, `/blog/media/*`, `/sitemap.xml` (правила в `static/.htaccess`).
- `static/_blog/ai.php` — ИИ: статьи (Claude, стрим), картинки (OpenAI `gpt-image-2`, фолбэк `gpt-image-1.5`),
  идеи тем (подсказки Google gl=kz и Яндекса lr=159 → Claude) и план выхода (1/2/3 статьи в неделю, 10:00).
- `static/_blog/auth.php`, `static/admin/` — вход, первая настройка по одноразовому коду, API админки.
- `static/_blog/admin.tpl` — интерфейс админки (десктоп и телефон).

**Данные** — на хостинге вне сайта, Plesk Git их не трогает: `/var/www/vhosts/alfimov.kz/alfimov-data/`
(`articles/*.json`, `media/` — загруженные и ИИ-картинки, `settings.json` — хэш пароля и ключи ИИ,
`sessions.json`, `jobs/`, `ideas.json`). В админке есть «Скачать копию всех статей».
`content/articles/` в репо — стартовый набор: при первом запуске переносится на хостинг (`_blog/seed`).

**Расписание** без cron: статья «на завтра» просто не отдаётся до своего времени (Алматы).

**Долгие операции ИИ** — задачи: браузер создаёт задачу, запускает её отдельным запросом и опрашивает статус.
В Plesk у PHP должен стоять `max_execution_time` 600: иначе хостинг обрывает запрос через ~2 минуты.

**SEO-автопилот** (`static/_blog/seo.php`, вкладка «📈 SEO» в админке) — раз в неделю сам:
Search Console по API (служебный аккаунт Google, JSON-ключ загружается во вкладке) → «близко к топу», просевшие страницы,
страницы, мешающие друг другу, мало кликов → правки статей (как «Подтянуть под запросы»; применяются кнопкой в Telegram,
в админке или автоматически по галочке); автоссылки между статьями (Claude подбирает фразы, ставятся при показе,
`alfimov-data/seo/links.json`); вопросы ChatGPT и Claude с поиском — советуют ли агентство; отчёт ботом в личку.
Cron не нужен: заходы на сайт раз в 10 минут проверяют, не пора ли, и пинают `/api/seo-tick.php` (с секретом);
работа идёт шагами до ~100 с (хостинг обрывает запросы на ~125 с), каждый шаг пинает следующий, оборванный повторяется.
Данные — `alfimov-data/seo/` (`state.json`, `report.json`, `history.json`, `analysis.json`).

**Забыли пароль** — удалить `alfimov-data/settings.json` в «Файлах» Plesk и пройти первую настройку заново
(нужен код настройки; ключи ИИ вставить снова, статьи не пострадают).

Локально: `python3 build.py` и `php -S 127.0.0.1:8090 -t dist <роутер>` (роутер повторяет правила `.htaccess`).

**SEO-аудит** (`seo_audit.py`, правила по мотивам аудита OpenSEO): title/description (есть, длина ≤60/≤160, дубли),
ровно один H1, уровни заголовков без пропусков, битые внутренние ссылки, страницы-сироты, картинки без alt, объём текста.
Сводка печатается при каждой сборке; `./deploy-git.sh` не выкладывает сайт при critical-ошибках.
Вручную: `python3 seo_audit.py`.

Тесты: `python3 -m pytest tests` (включает PHP-тесты `tests/php/test_*.php`, если установлен `php`).

## Деплой

Автоматический, без кнопок:

```
./deploy-git.sh
```

Скрипт собирает сайт и кладёт `dist/` новым коммитом в ветку `deploy`. GitHub-вебхук (push) дёргает
Plesk Git (репозиторий `alfimov-site.git`, ветка `deploy` → `/httpdocs`, режим «Автоматически»),
и через ~10 секунд новая версия на сайте. Какая сборка сейчас на хостинге — https://alfimov.kz/version.txt.

Статьи блога: после публикации в админке тоже нужен `./deploy-git.sh` (админка делает это сама).

Секреты формы — файл `tg-config.php` рядом с `httpdocs` на хостинге (вне репозитория).

Бот заявок (@alfimovkz_bot) общий для всех сайтов хостинга: alfimov.kz — главный (его `tg-config.php` и вебхук),
другие сайты (metalbaza.kz) берут токен отсюда и записывают себя в `/var/www/vhosts/alfimov.kz/tg-sites/`.
В боте «🔗 Привязать группу» спрашивает сайт — у каждого сайта своя группа. `static/api/_tg.php` одинаковый в обоих репозиториях.

`./deploy.sh` (FTPS) и workflow `.github/workflows/deploy.yml` — запасные варианты, сейчас не используются:
FTP-вход не настроен, а GitHub Actions на аккаунте заблокированы по биллингу.
